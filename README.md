# Electronics-Products-Sample-Website-Frontend-
# Electronics Products Showcase

## Overview

A multi-page frontend website designed to showcase sample electronic products. The project demonstrates a simple product listing interface and navigation between different pages.

## Technologies

This project was built using **vanilla web technologies** without any frameworks:

* HTML
* CSS
* JavaScript

## Features

* Multi-page website
* Product showcase layout
* Navigation between pages
* Separate CSS and JavaScript files for each page
* Clean and simple user interface

## Pages

The website includes several pages such as:

* Home
* Products
* Contact
* About 

## Running the Project

Simply open `index.html` in your browser to run the project locally.

## Deployment

The project can be deployed using GitHub Pages to make the website accessible online.

## Status

The project is mostly complete with only minor improvements remaining.
